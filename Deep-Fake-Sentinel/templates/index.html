Model honesty

No checkpoint, no confidence.

DeepFake Sentinel does not fabricate certainty. When a trained model checkpoint is absent or an analysis cannot be completed, the interface states the limit plainly.

Inconclusive — no trained checkpoint

  • Detection results are decision support, not proof of authenticity.
  • Trained artifacts live in ml_models; browser assets are demonstration only.
  • Confidence values appear only when the API reports a trained checkpoint and a numeric result.
  • Generative techniques evolve — analyst review and corroborating evidence remain essential.
